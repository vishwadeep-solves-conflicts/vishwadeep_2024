# vishwadeep-s.netlify.app

Source for my portfolio site: experience, skills, selected work and resume.

Built with React, TypeScript, Vite and plain CSS (three colour themes), and deployed on Netlify.

## Run locally

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build to dist/
```

The content lives in `src/data.ts`, the styles and themes in `src/index.css`, and the resume PDF in `src/assets/pdfs/`.
