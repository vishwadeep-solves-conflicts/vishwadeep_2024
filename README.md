# vishwadeep-s.netlify.app

Source for my portfolio site: experience, skills, selected work and resume.

Built with React, TypeScript, Vite, styled-components and GSAP, and deployed on Netlify.

## Run locally

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build to dist/
```

The content lives in `src/pages/` (Experience, Skills, Works) and the resume PDF in `src/assets/pdfs/`.
